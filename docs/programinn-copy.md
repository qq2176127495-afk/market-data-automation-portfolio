# 程序员客栈作品文案

## 名称

Python 行情数据采集与清洗脚本

## 简介

使用 Python 编写的数据采集脚本示例，主要演示通过 HTTP 请求获取公开 JSON 数据，并将字段整理后保存为 CSV 文件。该版本是公开展示/售卖的 Lite 版，只包含基础采集、字段清洗、文件保存和合成样例，不包含生产环境配置或私有业务逻辑。

## 技术栈

Python、Requests/urllib、JSON、CSV、命令行脚本、数据清洗

## 个人职责

负责脚本结构设计、接口数据读取、字段解析、CSV 落盘、样例数据整理和敏感内容隔离。

## 亮点

- 代码结构简单，便于二次开发。
- 支持将 JSON 数据整理为 CSV。
- 内置合成样例，不依赖密钥即可运行。
- 公开版本不包含账号、服务器、真实日志和核心私有参数。
